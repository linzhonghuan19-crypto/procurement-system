🔌 API 接口文档

系统提供完整REST API，可对接其他办公系统：

GET /api/products - 获取产品列表
POST /api/products - 创建产品
PUT /api/products/{id} - 更新产品
DELETE /api/products/{id} - 删除产品
GET /api/orders - 采购单列表
POST /api/orders - 创建采购单
POST /api/ai/analyze - AI分析
POST /api/wecom/send - 发送企微消息
POST /api/wecom/notify/low-stock - 低库存预警

所有API需在Header中添加: Authorization: Bearer {token}
